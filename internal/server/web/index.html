발급 주소: https://a7k2m9.tunnel.example.com (영문 소문자·숫자 6자리) · 웹 터널은 연결마다 공개 포트를 추가하지 않습니다. 와일드카드 DNS와 HTTPS 인증서를 먼저 연결하세요.
기존 TCP 포트 방식 (선택)
TCP 방식의 공개 주소는 IP/도메인:배정포트 형식입니다. 웹 터널에는 이 포트 범위를 사용하지 않습니다. 이 서버의 방화벽과 공유기에서 설정한 포트 범위를 허용해야 외부에서 접속할 수 있습니다.
SSH·관리 수신 주소 및 웹 터널 설정 변경은 재시작 후 적용됩니다. 설정 저장 시 현재 연결은 종료됩니다.
운영 안내
SSH는 암호화된 표준 TCP 터널을 제공합니다. SSH 셸·명령 실행·SFTP와 UDP/VPN 기능은 제공하지 않습니다.
외부 접속에는 SSH 수신 포트의 방화벽 허용과 공유기 포트포워딩이 필요할 수 있습니다. 관리 화면은 외부에 직접 공개하지 않습니다.


서버 프로그램에서 주소 자동 발급받기
① 서버 설정에서 자동 터널과 웹 기본 도메인을 설정하고 DNS·인증서를 연결합니다. ② 접속 계정에서 인증키를 발급합니다. ③ Go 연결 모듈로 터널을 엽니다.
session, err := tunnel.Open(ctx, tunnel.Options{
    Server: "relay.example.com:2222",
    User: "my-app",
    AccessKey: accessKey,
    Fingerprint: serverFingerprint,
    Target: "127.0.0.1:9000",
    Protocol: "http",
})
// 생성된 URL로 브라우저 접속 (포트 입력 불필요)
url := session.Endpoint().URL
연결 모듈은 pkg/tunnel, 브라우저 예제는 examples/web-demo에 있습니다. 웹 배포 문서는 docs/WEB-TUNNELS.md입니다. API 문서는 docs/TUNNEL-API.md를 확인하세요. 웹 터널은 HTTP·웹소켓을 중계합니다. 대상 앱 자체의 로그인은 유지되며 발급된 주소를 아는 사람은 접속할 수 있습니다.

아래 예시의 서버 주소, 계정, 키 경로와 포트를 실제 환경에 맞게 바꾸세요. 하나의 SSH 연결에 여러 -L·-R 옵션을 함께 지정할 수 있습니다.
Local · 서버 측 서비스에 연결
클라이언트의 13389 포트를 서버에서 접근 가능한 PC의 RDP 3389로 연결합니다.
Reverse · 클라이언트 측 서비스를 서버로 공유
클라이언트의 8080 서비스를 서버의 18080 포트로 전달합니다. 기본 수신은 서버 내부에서만 접근 가능합니다.
SOCKS5 · 목적지를 요청마다 선택
브라우저나 앱의 SOCKS5 프록시를 127.0.0.1:1080으로 지정합니다. 계정의 Local 목적지 정책이 동일하게 적용됩니다.
